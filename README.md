# 考研背单词 · 红宝书 + 真题词汇

考研英语单词学习单页应用（清华紫 · 薰衣草主题），由「红宝书背单词」与「真题词汇 2001-2024」两个页面合并而成。

**在线使用**：https://jlshdsdk.github.io/kaoyan-vocab/

## 词库
- 考研红宝书 · 全量词库：6712 词 / 135 单元
- 真题配套词汇 2001-2024：7457 词 / 159 单元（按年份排序）
- 双书重复词共享记忆进度；共 10645 个词条，全部内置、完全离线可用

## 功能
- SM-2 间隔重复刷词（新词/复习混合调度）、英译中四选一、看中文默写
- 生词本 / 错题本、打卡日历、学习量统计、词库浏览、Anki 导出
- 学习进度保存在浏览器 localStorage，首次打开自动合并旧版两页的进度
- 深色模式、TTS 发音

## 本地开发
`tools/build_merged_site.py` 从两个源页面重建 `index.html`（python3，无第三方依赖）。
